# Exort — голосовой лаунчер для Dota 2

Приложение для управления Dota 2 голосом на русском языке. Распознавание речи работает полностью офлайн через [Vosk](https://alphacephei.com/vosk/).

## Возможности

- Голосовой запуск игры по кодовому слову
- Голосовые команды: **затайми:** **байбек**, **глиф**
- Настраиваемый словарь фраз
- Поддержка нескольких аудиоустройств
- Тёмная/светлая тема с выбором акцентного цвета
- Полностью офлайн — интернет не нужен

## Требования

- Windows 10/11
- Python 3.11+
- Зависимости: `vosk`, `sounddevice`, `tkinter` (входит в стандартную библиотеку)

## Установка и запуск

```bash
pip install vosk sounddevice
python gaysexdota.py
```

Либо скачай готовый `.exe` из [Releases](../../releases).

## Сборка .exe

Сборка выполняется через PyInstaller:

```bash
pyinstaller Exort.spec
```

Собранный файл появится в папке `dist/Exort/`.

## Структура проекта

```
exort/          — исходный код приложения
model-ru/       — офлайн-модель Vosk (не включена в репозиторий, скачать отдельно)
words.txt       — встроенный список фраз по умолчанию
icon.ico        — иконка приложения
*.wav           — звуковые уведомления
```
